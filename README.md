# AskDB AI

AskDB AI is a Text-to-SQL application built with Python, MySQL, and Groq. It allows users to interact with a MySQL database using natural language.

The application uses the database schema to generate SQL queries with an LLM, validates the generated query before execution, executes it against MySQL, and uses a separate AI conversation to generate a human-readable response.

## Features

- Convert natural language questions into SQL queries
- Automatically discover the MySQL database schema
- Generate SQL using an LLM
- Validate generated SQL before execution
- Execute read-only queries on MySQL
- Display the generated SQL query
- Generate human-readable responses from query results
- Maintain AI conversation context for SQL generation
- Maintain separate AI conversation context for response generation
- Store query history for each session
- Log application, database, and AI activity
- Configuration using environment variables
- Modular object-oriented architecture

## How It Works

```text
User Question
      │
      ▼
Database Schema
      │
      ▼
SQL Generation AI
      │
      ▼
Generated SQL
      │
      ▼
SQL Validation
      │
      ▼
MySQL Database
      │
      ▼
Query Result
      │
      ▼
Response AI
      │
      ▼
Human-readable Answer
```

SQL generation and response generation use separate AI conversations to keep their responsibilities independent.

## Installation

Clone the repository.

```bash
git clone https://github.com/Eashwar-Raj-R/askdb-ai.git
cd askdb-ai
```

Install the dependencies.

```bash
uv sync
```

## Environment Variables

Create a `.env` file in the project root.

```env
HOSTNAME=localhost
USER=root
PASSWORD=your_password
DATABASE=your_database

GROQ_API_KEY=your_api_key
MODEL=openai/gpt-oss-120b
```

Make sure `.env` is included in `.gitignore` so that credentials are not committed to the repository.

## Database

AskDB AI requires a MySQL database.

The application automatically reads the database schema when it starts and stores the discovered table definitions in:

```text
metadata/table_definition.json
```

You can use your own MySQL database or the sample database included with the project.

## Run

Start the application with:

```bash
python main.py
```

The application will prompt you for a natural language question.

To exit:

```text
exit
```

or

```text
close
```

AI > Hey, How can I help you today?

JOIN drivers d ON r.driver_id = d.driver_id

## Query History

AskDB AI stores the questions asked during a session along with the SQL generated by the AI.

Example:

```json
[
    {
        "datetime": "2026-08-01 10:30:15",
        "human": "show all completed rides",
        "generated_sql": "SELECT ..."
    }
]
```

The history is stored in:

```text
metadata/query_history.json
```

## SQL Validation

Before executing an AI-generated query, AskDB AI checks the query for restricted SQL commands.

The current implementation blocks commands such as:

```text
INSERT
UPDATE
DELETE
TRUNCATE
DROP
MERGE
CREATE
ALTER
```

This provides a basic read-only protection layer before the query is sent to MySQL.

## Current Workflow

1. Connect to the MySQL database.
2. Discover the database tables and their definitions.
3. Store the discovered schema as metadata.
4. Send the schema and user question to the SQL generation AI.
5. Maintain SQL generation conversation context.
6. Generate a SQL query.
7. Validate the generated SQL.
8. Execute the query against MySQL.
9. Send the question and query results to the response AI.
10. Generate a human-readable response.
11. Store the question and generated SQL in the session history.
